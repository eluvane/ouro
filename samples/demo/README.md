# Demo samples

These programs run through the [native build and run commands](../../docs/tooling.md#native-program-compile).
A companion `.golden` file contains the expected output. A `.stdin` file
supplies input when the program reads from stdin.

Start with [Getting started](../../docs/getting_started.md#run-a-native-program)
to build and run [`01_hello.ouro`](01_hello.ouro).

Keep demos small and use the [current IO syntax](../../docs/syntax.md#io-and-do)
except in fixtures that intentionally cover legacy spelling.
