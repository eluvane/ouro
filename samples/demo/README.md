# Demo samples

Small runnable inputs with expected `.golden` and `.stdin` companions where available.

Start with [Getting started](../../docs/getting_started.md#run-a-native-program)
for a complete run of `01_hello.ouro`; the [command reference](../../docs/tooling.md)
covers other inputs.

Keep demos small and use the [current IO syntax](../../docs/syntax.md#io-and-do)
except in fixtures that intentionally cover legacy spelling.
