Work through these six modules in order. First
[build the toolchain and check a module](../../docs/getting_started.md).

| --- | --- |
| [`01_hello.ouro`](01_hello.ouro) | Definitions and functions |
| [`02_nat.ouro`](02_nat.ouro) | Inductive natural numbers |
